MRI4 classes · VGG16

Brain Tumour Classification from MRI with Transfer LearningFinal year project

Medical imaging · Computer vision · Deep learning
University of Sahiwal, 2025

A four-way classifier for brain MRI scans — glioma, meningioma, pituitary tumour and no tumour — built by fine-tuning a pre-trained VGG16 network and served through a web application for single-scan inference. Reached 94% accuracy on the held-out validation set.

Code
Method and results

Motivation

Reading brain MRI is slow and subject to inter-observer variability. A classifier that triages scans can shorten the path to a specialist's attention.

Method

VGG16 pre-trained on ImageNet, fine-tuned on a labelled brain MRI dataset in TensorFlow/Keras. Scans were resized, normalised and augmented (rotation, flips, zoom) to limit overfitting on a small dataset. Inference is wrapped in a Flask application that accepts an uploaded scan and returns the predicted class.

Results

  • 94% accuracy on the held-out validation set.
  • Four-class output: glioma, meningioma, pituitary tumour, no tumour.
  • End-to-end deployment: upload a scan, get a prediction in the browser.

RAGMulti-agent · LLaMA-3.3

MediScan — Grounded Question Answering over Medical Reports

NLP · LLMs · Retrieval-augmented generation
Independent project, 2025

A multi-agent retrieval-augmented system that takes an uploaded medical report and answers questions about it in plain language, with every answer drawn from passages retrieved from the document rather than from the model's own memory.

Code
Method and results

Motivation

Patients receive lab reports they cannot read. A system that answers questions about a specific document is useful only if it refuses to invent findings, which makes retrieval grounding the central design constraint.

Method

Uploaded PDFs are parsed, chunked and embedded into a FAISS index. A retrieval agent selects the relevant passages; a generation agent (LLaMA-3.3 via the Groq API, orchestrated with LangChain) answers using only those passages. Served as a Flask application.

Results

  • Working end-to-end RAG pipeline over user-supplied medical PDFs.
  • Separation of retrieval and generation into distinct agents.
  • Answers traceable to the passages they came from.
PythonLangChainFAISSLLaMA-3.3Groq APIFlask

Phishing Website Detection from URL Features

NLP · Machine learning · Security
Independent project, 2025

A classifier that labels a URL as legitimate or phishing from the string alone, using lexical and host-based features. Logistic regression reached 96.5% accuracy, ahead of the Naive Bayes and tree-based baselines it was compared against.

Code
Method and results

Motivation

Page content takes time to fetch and can be cloaked. A detector that works on the URL alone can run before a page loads.

Method

Lexical features — length, token counts, special-character frequency, suspicious substrings — extracted with NLTK and scikit-learn, then used to train and compare several classifiers under the same split. Packaged as a Streamlit demo that scores a pasted URL.

Results

  • 96.5% accuracy with logistic regression.
  • Like-for-like comparison across several model families.
  • Interactive demo for scoring arbitrary URLs.
Pythonscikit-learnNLTKStreamlit
GTSRB43 classes · CNN

Traffic Sign Recognition with Convolutional Networks

Computer vision · Deep learning
Independent project, 2025

A convolutional network trained on the German Traffic Sign Recognition Benchmark that classifies 43 sign categories from camera images, reaching roughly 94% test accuracy across varying lighting and orientation.

Repository link to be added
Method and results

Motivation

Driver-assistance systems need sign recognition that holds up in poor light and at odd angles, at frame rate.

Method

A CNN trained from scratch in Keras on GTSRB, with augmentation and early stopping to control overfitting across the long tail of rare sign classes. Predictions served through a Flask interface.

Results

  • ~94% test accuracy over 43 categories.
  • Stable under changes in lighting and orientation.
  • Browser-based inference on uploaded images.
